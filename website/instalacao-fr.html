Installation

Installer, pas à pas

Les paquets de chaque système sont sur la page des versions ; le plus récent est en haut. Les avertissements de sécurité ci-dessous sont attendus. Ils n'indiquent aucun problème et n'apparaissent que la première fois.

Windows

  1. Téléchargez aquorbium-<version>-win64.exe.
  2. Ouvrez-le. Windows affiche une boîte bleue « Windows a protégé votre ordinateur » : cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
  3. Si Windows demande l'autorisation d'administrateur, cliquez sur « Oui ».
  4. Cliquez sur « Suivant » jusqu'au bout. La dernière page a déjà « Lancer Aquorbium » coché. Aquorbium est alors dans le menu Démarrer et sur le bureau.

Sans installer : décompressez aquorbium-<version>-win64.zip et ouvrez Aquorbium.exe.

macOS

  1. Téléchargez aquorbium-<version>-Darwin.dmg. Il fonctionne sur les Mac Intel et Apple Silicon.
  2. Ouvrez-le et glissez Aquorbium dans Applications.
  3. Ouvrez-le. La première fois, macOS bloque l'app avec un message disant qu'Apple n'a pas pu confirmer qu'elle est exempte de logiciel malveillant. Vous pouvez aussi voir « impossible de vérifier le développeur » ou « est endommagée et ne peut pas être ouverte ». Dans tous les cas :
    • Ce n'est ni un défaut ni un virus : l'app est signée ad hoc, sans Developer ID payant d'Apple.
    • Cliquez sur « OK » ou « Terminé », pas sur « Placer dans la corbeille ».
  4. Autorisez l'app, une fois, de l'une de ces façons :
    • Dans Réglages Système : allez dans Confidentialité et sécurité, descendez jusqu'à la section sécurité, cliquez sur « Ouvrir quand même », confirmez avec votre mot de passe ou Touch ID, puis cliquez sur « Ouvrir ». Sous macOS 14 ou antérieur : clic droit sur l'app dans le Finder → Ouvrir → Ouvrir.
    • Dans le Terminal, si le bouton n'apparaît pas :
xattr -dr com.apple.quarantine "/Applications/Aquorbium.app"

Si rien ne s'affiche, c'est réussi. La commande retire seulement la « marque de quarantaine » que macOS pose sur tout fichier téléchargé.

Linux

  • Ubuntu 22.04+, Debian 12+, Mint 21+ : double-cliquez sur le .deb, ou lancez sudo apt install ./aquorbium-<version>-Linux.deb.
  • Fedora, Arch, openSUSE et autres distributions :
    • AppImage : rendez-le exécutable (Propriétés → autoriser l'exécution, ou chmod +x) et ouvrez-le.
    • .tar.gz : décompressez-le et lancez ./install.sh. Il installe pour votre utilisateur seulement, sans root ; ./install.sh --remove annule.

À la première ouverture

  1. Chaque ouverture est une nouvelle pièce. La graine de la session propose un biome - l'eau, la lumière, la population, les corps, les modules qui s'éveillent - et un monde de tonalités, d'harmonie et de forme. Avec VARIE allumé (bande du bas), les commandes bougent aussi lentement toutes seules. Jouez à partir de là.
  2. Le bouton TUTORIEL explique l'instrument pas à pas, et LEARN explique toute commande que vous pointez, en anglais, portugais, français ou espagnol (le bouton de langue : EN/PT/FR/ES).
  3. AUDIO choisit la sortie. CASQUE place chaque organisme autour de votre tête : au casque seulement.
  4. Le microphone (la SALLE) reste éteint jusqu'à ce que vous l'allumiez.

Problèmes et solutions

Windows : « Windows a protégé votre ordinateur ». Cliquez sur « Informations complémentaires », puis « Exécuter quand même ». Si un antivirus met Aquorbium.exe en quarantaine, restaurez-le et autorisez-le : le programme est construit par l'intégration continue publique de ce dépôt, à partir de ce code.

macOS : « endommagée », « impossible de vérifier le développeur » ou « Apple n'a pas pu confirmer ». Suivez l'étape 4 de macOS : Ouvrir quand même dans Confidentialité et sécurité, ou la commande xattr dans le Terminal.

Linux : la fenêtre ne s'ouvre pas. Installez le .deb avec apt, qui installe aussi les dépendances. Avec l'AppImage ou le .tar.gz, le système a besoin d'ALSA, FreeType, Fontconfig, X11 et GLib, présents sur tout bureau. Si l'AppImage ne s'ouvre pas, installez libfuse2 (Ubuntu 22.04+ : sudo apt install libfuse2), ou lancez-la avec ./aquorbium-<version>-linux-x86_64.AppImage --appimage-extract-and-run.

Pas de son. Cliquez sur AUDIO et choisissez la sortie. Vérifiez aussi le NIVEAU DE SORTIE dans l'en-tête, et que MUET et PAUSE sont éteints.

Clics ou coupures. Dans AUDIO, choisissez un tampon de 512 échantillons. Sous Linux, le fil audio demande la priorité temps réel ; la ligne d'état affiche RT 70 quand il l'obtient et RT non sinon. Pour l'autoriser, ajoutez votre utilisateur au groupe audio ou pipewire (selon la distribution) et redémarrez l'ordinateur. Des programmes lourds à côté de l'Aquorbium (compilateurs, vidéo) causent aussi des coupures.

Autre chose : écrivez à rasgo.instruments@gmail.com avec votre système et sa version, ce que vous avez fait et le message affiché. Vous pouvez aussi ouvrir une issue.

Configuration requise

WindowsWindows 10 ou 11, 64 bits
macOS10.15 ou plus récent ; Intel et Apple Silicon (Universal 2)
Linuxx86-64 avec glibc 2.35 ou plus récente (distributions de 2022 et après)
Processeur64 bits, deux cœurs ou plus. Mesuré sur un Intel Core i5-6500 (2015, 4 cœurs), à 48 kHz et blocs de 512 échantillons : l'audio utilise environ 7 % du temps de chaque bloc (au plus 9 %)
Mémoireenviron 55 Mo en jeu (mesuré)
Disqueenviron 15 Mo
Audiotoute sortie ; un microphone seulement pour la SALLE

La valeur du processeur a été mesurée sur la machine de l'auteur. Des machines plus faibles n'ont pas été testées.

Compiler depuis le code

git clone https://github.com/lucioaraujo/aquorbium.git
git clone --branch 9.0.3 https://github.com/juce-framework/JUCE.git
cmake -S aquorbium -B aquorbium/build -DCMAKE_BUILD_TYPE=Release -DAQUORBIUM_JUCE_PATH=$PWD/JUCE
cmake --build aquorbium/build --parallel 2
(cd aquorbium/build && ctest -LE slow --output-on-failure)

Sous Linux, la compilation de JUCE demande les paquets de développement d'ALSA, FreeType, Fontconfig, X11 et GTK. Le flux .github/workflows/package.yml en donne la liste.

État

La version 0.1.0 est la première version publique. Les paquets Windows et macOS sont construits, testés et vérifiés par l'intégration continue : sans dépendance au Visual C++ Redistributable, et un paquet Universal 2 scellé sur macOS. Ils n'ont pas encore été ouverts par l'auteur sur de vrais Windows et Mac.
